## ✅ Instrucciones para el jurado verificador

Existen tres formas de verificar lo ejecutado:

### Opción 1 — Ver los resultados ya ejecutados (recomendada, sin instalar nada)

1. En la lista de archivos de este repositorio, haga clic en el notebook que
   desea revisar (por ejemplo, `AZIMUTH_01_Validacion_Sintetica_VS_Colab_.ipynb`).
2. GitHub mostrará directamente en el navegador:
   - El **código fuente** de cada celda.
   - Los **gráficos** generados (figuras en formato PNG incrustadas).
   - Las **tablas** de resultados (tablas HTML renderizadas).
   - Las **salidas de texto** (métricas, resúmenes e impresiones de consola).
3. Todo lo visible corresponde a la ejecución realizada en Google Colab;
   no se requiere ninguna acción adicional.

### Opción 2 — Re-ejecutar los notebooks en Google Colab

1. Haga clic en el botón **"Open in Colab"** de la tabla anterior
   (o en el enlace directo del notebook que desee verificar).
2. Una vez abierto en Google Colab, vaya al menú
   **Entorno de ejecución → Ejecutar todas** (*Runtime → Run all*).
3. Colab ejecutará todas las celdas en orden y reproducirá los mismos
   gráficos, tablas y resultados evidenciados en este repositorio.

### Opción 3 — Descargar y ejecutar localmente

```bash
git clone https://github.com/u201100037/TSP-Eduardo-Manuel-Huerta-Ycochea.git
```

Luego abra los archivos `.ipynb` con Jupyter Notebook, JupyterLab o VS Code
y ejecute todas las celdas.
